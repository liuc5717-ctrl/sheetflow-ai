# SheetFlow AI

SheetFlow AI is a lightweight, responsive workflow processing tool designed to streamline spreadsheet and tabular data automation. Built with a clean Python backend and a lightweight HTML frontend, it helps developers and teams process workflows with minimal setup.

---

## 🚀 Features

- **Workflow Automation**: Automates repetitive data cleaning, conversion, and workflow operations.
- **Intuitive Web UI**: Simple, responsive interface built with native HTML and JavaScript.
- **Fast Execution**: Python-powered backend for reliable and rapid processing.
- **Easy Deployment**: Minimal dependencies, ready to run locally or integrate into existing pipelines.

---

## 🛠️ Tech Stack

- **Backend**: Python 3.x
- **Frontend**: HTML5, Modern CSS, JavaScript
- **Dependencies**: Listed in `requirements.txt`
